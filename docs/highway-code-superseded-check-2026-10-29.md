# Highway Code: 2013 print vs current GOV.UK (29 Oct 2026)

Source PDF: `Highway-Code-pdf.compressed-1.pdf` (153 pages, metadata 2010/2017, print run 21/10/2013). Charlie confirmed it is the newest copy he has, so every question is written from the current GOV.UK text (OGL, `supersededCheck: 'current'`) and the PDF is used only for cross-checking. No PDF text or images are in the repo.

Method: for each of the 307 current numbered rules (excluding annexes), the first and last 8 words were searched in the PDF text. 74 rules did not match at one end, so they are worded differently from the print or are new. This is a coarse screen: a rule changed only in its middle (for example some of the 2022 changes) can pass it, so it lists *at least* these rules, not all changes.

Rules with different wording or position: 275, 276, 277, 278, 279, 280, 281, 282, 283, 284, 103, 105, 107, 108, 109, 124, 126, 128, 129, 138, 140, 142, 148, 149, 253, 255, 256, 257, 258, 262, 263, 264, 266, 269, 270, 271, 204, 210, 212, 213, 215, 217, 220, 290, 293, 52, 59, 61, 62, 63, 71, 72, 73, 74, 75, 76, 77, 78, 79, 82, 89, 96, 97, 98, 87, 1, 5, 6, 8, 13, 192, 195, 199, 250.

Known structural changes since the print: hierarchy of road users (H1-H3) and the rewritten junction, crossing, overtaking and passing-clearance rules (2022); Dutch reach (rule 239); breakdowns now rules 275-287 and motorways 253-274; mobile phone and speed-limit updates (including Wales's 20 mph default).
